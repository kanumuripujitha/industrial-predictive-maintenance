# Data Dictionary

## Overview

This document describes the main datasets generated by the Industrial Predictive Maintenance Synthetic Data Generator.

All records are synthetic and intended for development, testing, and analytics demonstrations.

## 1. plants.csv

| Column | Description |
|---|---|
| `plant_id` | Unique plant identifier |
| `plant_name` | Plant name |

## 2. production_lines.csv

| Column | Description |
|---|---|
| `line_id` | Unique production-line identifier |
| `plant_id` | Plant associated with the line |
| `line_name` | Production-line name |

## 3. machines.csv

| Column | Description |
|---|---|
| `machine_id` | Unique machine identifier |
| `line_id` | Production line associated with the machine |
| Other columns | Machine attributes generated by the script |

## 4. sensors.csv

| Column | Description |
|---|---|
| `sensor_id` | Unique sensor identifier |
| `machine_id` | Machine associated with the sensor |
| `sensor_type` | Type of measurement, such as temperature or vibration |
| `min_value` | Minimum allowed sensor value |
| `max_value` | Maximum allowed sensor value |

## 5. telemetry_events.csv

| Column | Description |
|---|---|
| `telemetry_id` | Unique telemetry-event identifier |
| `sensor_id` | Sensor that produced the reading |
| `timestamp` | Time of the reading |
| `value` | Recorded synthetic sensor value |

## 6. failure_events.csv

| Column | Description |
|---|---|
| `failure_event_id` | Unique failure-event identifier |
| `machine_id` | Machine associated with the event |
| `sensor_id` | Sensor associated with the event |
| `timestamp` | Synthetic failure timestamp |
| `failure_type` | Assigned failure category |
| `severity` | Assigned severity |
| `label` | Synthetic failure label |
| `ground_truth_source` | Indicates that the label is synthetic |

## 7. maintenance_work_orders.csv

| Column | Description |
|---|---|
| `work_order_id` | Unique work-order identifier |
| `failure_event_id` | Related failure event |
| `machine_id` | Machine receiving maintenance |
| `technician_id` | Assigned technician |
| `part_id` | Associated spare part |
| `created_at` | Work-order creation timestamp |
| `completed_at` | Work-order completion timestamp |
| `status` | Work-order status |
| `maintenance_type` | Type of maintenance |

## 8. technicians.csv

| Column | Description |
|---|---|
| `technician_id` | Unique technician identifier |
| Other columns | Technician attributes generated by the script |

## 9. parts.csv

| Column | Description |
|---|---|
| `part_id` | Unique part identifier |
| Other columns | Part attributes, including generated cost information |

## 10. operating_shifts.csv

Contains operating-shift definitions, including shift identifiers, names, and scheduled hours.

## 11. machine_risk_scores.csv

| Column | Description |
|---|---|
| `machine_id` | Machine being assessed |
| `temperature_risk` | Temperature-related risk component |
| `vibration_risk` | Vibration-related risk component |
| `pressure_risk` | Pressure-related risk component |
| `risk_score` | Calculated heuristic risk score |
| `risk_level` | Risk category assigned by the script |

## Notes

- Primary identifiers are intended to uniquely identify records.
- Foreign-key columns connect related datasets.
- Sensor readings are synthetic and constrained by configured sensor limits.
- Risk scores are heuristic values, not calibrated probabilities of failure.
- Exact column names and data types should be confirmed against the generated CSV files and source code.
